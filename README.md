# Shopping Cart Practice

A browser shopping-cart exercise for product quantities, prices and totals.

**Category:** JavaScript applications

[All projects](https://github.com/maamg/maamg/blob/main/PROJECTS.md) · [Programming practice](https://github.com/maamg/jhalai)

## Open locally

Open `index.html` in a browser, or serve the repository folder:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000/index.html`. Keep the existing asset folders beside the HTML files. Internet access is needed for externally loaded fonts, styles or APIs.

## Main files

- `index.html`
- `index.md`
- `style.css`
